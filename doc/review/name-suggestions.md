Good instinct — "Vibeformer" signals *vibe-coding* (improvised, unverified LLM output), which is the exact opposite of what this project is: fail-closed, mechanical, differentially-proven translation. The name should signal fidelity and determinism instead.

## Top picks

- **Calque** — In linguistics, a calque is a word-for-word *loan translation*: a phrase rebuilt in a new language piece by piece while preserving its structure. That is precisely what this tool does to Java. Short, a real word, brandable, no significant software collisions, and reads well as a CLI: `calque generate pdfcube-io`.
- **Transpose** — Music: the same piece rendered in a different key; math: a deterministic structural transform. Both connotations fit "same semantics, different language." Clean verb for a CLI.
- **Pantograph** — The mechanical linkage draftsmen used to reproduce a drawing exactly at another scale. A machine that faithfully copies an original's every movement is a near-perfect metaphor for mechanical source translation. Distinctive; slightly long.
- **Homolog** — Biology: the same gene expressed in a different species, descended from a common ancestor. "PdfCube is the homolog of PDFBox on .NET" describes the product exactly.

## More by theme

**Linguistics / translation**
- **Cognate** — words in two languages sharing an ancestor; the generated C# is a cognate of the Java.
- **Verbatim** — says fidelity directly, but note Verbatim is a well-known storage-media trademark.

**Mechanical reproduction**
- **Diecast** — precise reproduction from a mold; also puns on "cast" for a type-savvy audience.
- **Mimeo** — from mimeograph, the mechanical copier (mimeo.com is a print company, minor).
- **Recast** — literally what happens to the source; generic enough that collisions exist but usable.

**Structure preservation**
- **Isomorph** — a structure-preserving mapping is the mathematical name for the goal; adjacent to "isomorphic JS" jargon but not colliding.

## Names to avoid

- **Babel** (the JS transpiler owns it), anything with **Sharp** (ReSharper adjacency), **Foundry** (Palantir), **Portage** (Gentoo's package manager), **Rosetta** (Apple), coffee puns generally (crowded and cutesy).

If I had to pick one: **Calque**. It's the only word in English whose dictionary definition is essentially "a mechanical, structure-preserving translation" — and it leaves "vibe" behind without overcorrecting into something sterile.
